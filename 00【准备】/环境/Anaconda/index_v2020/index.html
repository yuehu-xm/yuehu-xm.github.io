    安装路径，打开Anaconda Prompt

    2.3.1.conda指令¶

    创建 

    conda create -n torch_env python==3.8
conda activate torch_env
conda install numpy pandas matplotlib
conda deactivate 

    conda create -n torch2_env python==3.9 -y
conda activate torch2_env
conda install numpy pandas matplotlib scikit-learn -y
conda deactivate
    查看conda信息 
    conda info

    查看pip list信息 

    conda list

    查看conda虚拟环境信息 

    conda env list
# conda info -e
