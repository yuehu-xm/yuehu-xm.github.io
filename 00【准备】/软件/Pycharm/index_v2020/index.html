    3.1.4.Pycharm中添加方法的注解.¶

    使用方式为，在方法名下方输入三个双（单）引号，回车，自动生成。五种风格的样式如下：

    def docstrings_func_plain(parm_a, parm_b, parm_c):
    """
    Plain 风格
    """


def docstrings_func_epytext(parm_a, parm_b, parm_c):
    """
    Epytext 风格

    @param parm_a: 参数a
    @param parm_b: 参数b
    @param parm_c: 参数c
    @return: 结果a
    """


def docstrings_func_restructuredtext(parm_a, parm_b, parm_c):
    """
    reStructuredText 风格

    :param parm_a: 参数a
    :param parm_b: 参数b
    :param parm_c: 参数c
    :return: 结果a
    """


def docstrings_func_numpy(parm_a, parm_b, parm_c):
    """
    NumPy 风格

    Parameters
    ----------
    parm_a : 参数a
    parm_b : 参数b
    parm_c : 参数a

    Returns
    -------
    result_a : 结果a
    """


def docstrings_func_google(parm_a, parm_b, parm_c):
    """
    Google 风格

    Args:
        parm_a: 参数a
        parm_b: 参数b
        parm_c: 参数c

    Returns:
        result_a  结果a
    """

    PyCharm快捷键大全¶

    https://zhuanlan.zhihu.com/p/83987698

    运行编译

    • Ctrl+F9 【构建】
    • Shift+F10 【运行】
    • Ctrl+Shift+F10 【运行当前文件】
    • Ctrl+Alt+Enter 【向上插入一行】
    • Shift+Enter 【向下插入一行】
    • Ctrl+D 【复制粘贴一行】
    • Ctrl+Y 【删除一行】
    • Alt+Shift+Up+Down 【选中代码移动】
    • Ctrl+Shift+Up+Down 【可以移动当前方法体,如果移动一行代码只能在代码体内移动】

    同时编辑多行

    https://www.jianshu.com/p/5056e6952cc4

    https://blog.csdn.net/bingocoder/article/details/103760422

    • Ctrl+Left Button+Up+Down 【可以在同一列增加光标】
    • Ctrl+Shift+Alt+Left Button 【可以在任意位置增加光标】

    设置好光标后就可以松开按键使用 Shift+Ctrl+Left+Right，可以选中光标后面的代码，进行多行编辑。

    • Ctrl+/ 【单行注释】
    • Ctrl+Alt+L 【格式化代码】
    • Ctrl+Shift+U 【大小写转换】
    • Ctrl+Shift+Enter 【补全代码】
    • Shift+F6 【重命令】

    替换查找

    • Shift+Shift 【查看资源文件】
    • Ctrl+R 【替换】
    • Ctrl+F 【查找】
    • Ctrl+P 【查看参数】
    • Ctrl+Z 【撤销】
    • Ctrl+Shift+Z 【反撤销】
    • Tab 【缩进】
    • Shift+Tab 【不缩进】

    • Ctrl+Shift+A 【万能命令行】

    • Ctrl+Alt+S 【设置】
